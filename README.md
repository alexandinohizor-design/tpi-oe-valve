# tpi-oe-valve
TPI Organización Empresarial (UTN FRP): Enfoque sistémico, organigrama formal y análisis estructural de Valve Corporation; metas e indicadores de control; modelo de datos y procesos BPMN 2.0 (concurrencia y transacciones) para un indexador de metadatos en Steam, gestionado con metodología ágil e IA crítica.
